# Student Dropout Prediction System 🎓

An interactive Machine Learning application that predicts student dropout risks using a **Random Forest Classifier**.

## 🚀 Features
* **Predictive Modeling:** Uses Random Forest to analyze student data.
* **Interactive UI:** Simple interface for real-time predictions.
- **Data Analysis:** Includes preprocessing and visualization logic.

## 🛠️ Tech Stack
* **Language:** Python
* **ML Library:** Scikit-Learn
* **Data Handling:** Pandas & NumPy

## 📋 How to Run
1. Clone the repo.
2. Install dependencies: `pip install pandas scikit-learn`
3. Run the app: `python app.py`
